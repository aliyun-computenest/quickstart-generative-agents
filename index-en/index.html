Generative Agents Community Edition Deployment Documentation

Overview

The Generative Agents Community Edition is a service deployed based on the open-source code from the paper "Generative Agents: Interactive Simulacra of Human Behavior," published in April 2023 by researchers from Stanford University and Google Research. This study used technologies like ChatGPT to simulate a scenario where 25 characters live together in a virtual world. These characters possess distinct fictional personalities and engage in activities through spontaneous actions. Set in a retro RPG-style environment, they have independent lifestyle patterns, ranging from waking up and working to playing. Characters can communicate via natural language, exchanging information and forming memories through encounters and conversations.

In an evaluation, these generated agents produced credible individual and emergent social behaviors. For example, starting from a user-specified concept where one agent wanted to host a Valentine's Day party, the agents proactively invited others to the party over the next two days, made new acquaintances, arranged dates at the party, and coordinated to attend together at the appropriate time. The paper demonstrates that by integrating Large Language Models with computational interactive agents, this work introduces architectural and interaction patterns that enable credible simulations of human behavior.

Compute Nest has now listed Generative Agents based on open-source code. You only need to select the Elastic Compute Service (ECS) parameters on the creation page, and Compute Nest will automatically create an ECS instance with Generative Agents for you. After creation, you simply log in to the ECS to experience the Generative Agents virtual community. This document introduces how to activate the Generative Agents service on Compute Nest, as well as the deployment process and usage instructions. If you encounter any issues during use, feedback and discussion are welcome.

2.2 Specific Steps

Create the service by following the steps below:

  1. Create a service instance and fill in the service instance name (optional).
  2. Select the region, such as "Singapore" in the figure below.
  3. Select the instance type: Default is ecs.g6.large.
  4. Configure the instance password.
  5. OpenAI Key Configuration: Enter the OpenAI Key corresponding to your OpenAI account, formatted as "sk-...". Compute Nest only passes this OPENAI Key to Generative Agents as a credential for calling the API and will not perform any operations such as recording, validation, or authentication. To ensure normal subsequent use, please ensure that the account corresponding to this Key has access permissions and sufficient balance.
  6. Select the deployment zone, such as "Zone A" in the figure below.
  7. VPC Settings: Choose to create a new one or fill in existing VPC/VSwitch.
  8. Click Next to enter the order confirmation page.
  9. Check the checkbox for "I have read and agree to the 'Compute Nest Service Agreement'".
  10. Click "Create Now" in the bottom left corner to create the service instance.

3. Start Generative Agents Service

View Service Instance: After the service instance is successfully created, the deployment takes about 1-2 minutes. Once deployment is complete, you can see the corresponding service instance on the page.

Click on the service instance to enter the service instance details.

Click the login address to view the following interface in your browser, indicating that the frontend service has started successfully:

Next, you need to start the backend service via command-line interaction. First, log in to the ECS instance. Click: Resources > Remote Connection > Password-Free Login.

Select Session Management - Cloud Assistant and click Confirm to enter the ECS.

After entering the instance, execute the following commands to start the backend simulator service:

sudo su
conda activate agent
cd /home/ecs-assist-user/generative_agents/reverie/backend_server
python reverie.py

Upon successful execution, you will see the following output, appearing as a command prompt asking: "Enter the name of the forked simulation: "

To start a simulation with 3 agents including Isabella Rodriguez, Maria Lopez, and Klaus Mueller, enter the following:

base_the_ville_isabella_maria_klaus

Then it will prompt: "Enter the name of the new simulation:". Enter any name to represent your current simulation (e.g., just enter "mytest-simulation"). Note that you need to enter a different name each time you start, otherwise, the startup will fail.

If you want to enter an existing name and start normally, you need to delete the folder with the same name already created in the directory /home/ecs-assist-user/generative_agents/environment/frontend_server/storage in advance.

simulation-test-1

In your browser, navigate to http://{{Instance Public IP}}:8000/simulator_home. You should see the map of Smallville and a list of active agents on the map. You can move around the map using the keyboard arrow keys. Please keep this tab open. To run the simulation, type the following command in your simulation server when responding to the "Enter option" prompt:

run <step-count>

Please note that you need to replace <step-count> with an integer representing the number of game steps you want to simulate. For example, if you want to simulate 100 game steps, you should enter run 100. One game step represents 10 seconds of time in the game. Your simulation should be running, and you will see agents moving on the map in your browser (you can view the map using the up, down, left, and right arrow keys). Once the simulation run is complete, the "Enter option" prompt will reappear. At this point, you can simulate more steps by re-entering the run command and entering your desired number of game steps, exit the simulation without saving by entering exit, or save and exit by entering fin. The next time you run the simulation server, you can access the saved simulation by providing your simulation name as the forked simulation. This will allow you to restart the simulation from where you left off.
